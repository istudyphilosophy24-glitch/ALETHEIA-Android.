# ALETHEIA — Native Android Philosophy Reader

Native Android project for studying Martin Heidegger's *Being and Time*.

## Build on GitHub (no PC needed)
Upload the original file named `AletheiaNative-source.zip` from the ChatGPT conversation to the root of this repository using **Add file → Upload files**. Do **not** unzip or rename it. GitHub Actions will automatically unpack the source and attempt a debug APK build.

Go to **Actions → Build ALETHEIA Native APK** and open the latest run. Once it succeeds, download the artifact named `ALETHEIA-debug-APK`.

## What's inside
The archive contains Android Java source for an offline reader, two translation import slots, a native TTS audio interface, glossary, annotations, diagrams, philosophical experiments, and exercises.

**Important:** The full Macquarrie–Robinson and Stambaugh texts are copyrighted and are **not included**; import DRM-free, lawfully obtained text into the respective local editions.

This is an early source prototype, not a tested release APK.
