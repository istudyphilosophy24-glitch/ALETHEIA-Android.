# FOLIO Crema Reader
The FOLIO source project is stored in the `FOLIO-source.zip` snapshot in this development branch; the GitHub Actions workflow automatically unpacks it and compiles an Android 4.4-compatible APK on push.
The original ALETHEIA app on `main` is unaffected.
To download the APK: Actions → FOLIO Crema APK → latest successful run → Artifacts → FOLIO-Crema-Android4.4-APK.
This is a prototype; device and battery tests are still required.
